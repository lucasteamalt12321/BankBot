# School Project Plan: «Мой личный учебный портал» (9 класс, информатика)

Дата записи: 2026-08-19
Статус: план утверждён пользователем, реализация начата (Блок 1).

## Контекст

У пользователя в 9 классе обязательный проект по информатике. Он преподносит свой
личный сайт (LTHub, созданный под его собственные нужды) как школьный проект.
Требование: **не удалять** уже написанный код и функционал — только добавлять и
документировать.

## Тема проекта (для защиты)

> «Мой личный учебный портал: от Telegram-бота до платформы подготовки к ОГЭ»

История подаётся как эволюция проекта под свои нужды:
бот → банк/монеты → веб-портал → **учебные модули** (подготовка к ОГЭ).

## Ответы пользователя (2026-08-19)

- Объём математики: ~60–80 задач, 6–8 тем.
- Покрытие: **вся часть 1 ОГЭ по математике** + не только математика, а ещё физика,
  информатика, русский, история — в разных модулях.
- Режим «Тест»: **счёт + таймер**.
- Прогресс: **localStorage + hubTrack** (общая система достижений), без отдельной БД.
- Старт: сначала показать полный план письменно → план показан → «запиши и начинай».

## Уже существующий «школьный» фундамент (демонстрировать)

| Модуль | Предмет | Сюжет для защиты |
|--------|---------|------------------|
| `/emperors` Императоры России | История | Тренажёр с интервальными повторениями SM-2 (алгоритмы) |
| `/irregular_verbs` Практика глаголов | Английский | AI-генерация заданий, роли учитель/ученик |
| Reading trainer (тренажёр чтения) | Начальная школа | Озвучивание (Web Speech API), печать |
| `/trivia` Викторина | Гуманитарные знания | Вопросы по канону |
| `/achievements` Достижения и стрик | Геймификация | Мотивация, 100 достижений |

Итого после добавления модулей подготовки к ОГЭ получается **5+ школьных предметов**:
математика, физика, информатика, русский, история, английский — сильный аргумент
«платформа для учёбы».

## План: 3 блока

### Блок 1 — Учебный раздел с 4 новыми предметами (код)

#### 1.1. Единый «движок» тренажёра
Один общий модуль вместо копирования страницы императоров 4 раза:
- Страница `/school/<subject>` (одна на все предметы): общий HTML + JS
  (тренировка / тест / счёт / таймер / пояснения).
- Данные предмета подтягиваются JSON-ом при рендере.
- Аргумент для защиты: «архитектура без дублирования — 4 предмета на одном движке».

#### 1.2. Данные (лёгкие stdlib-пакеты, паттерн `core/history/emperors.py`)
- `core/school/math.py` — **60–80 задач, 6–8 тем**, номера 1–19 части 1 ОГЭ
  (выражения, уравнения, проценты, графики, прогрессии, геометрия, комбинаторика).
- `core/school/physics.py` — 40–60 задач (механика, теплота, электричество, оптика).
- `core/school/informatics.py` — 40–60 задач (алгоритмы, логика, кодирование, таблицы).
- `core/school/russian.py` — 40–60 заданий (орфография, пунктуация, лексика, синтаксис).
- Каждая задача: `Task(topic, question, options?, answer, explanation, difficulty)`
  + пояснение для тренировки.

#### 1.3. Страница `/school/<subject>`
- Вкладки «Тренировка» (пояснение сразу) и «Тест» (счёт + таймер).
- Счёт в localStorage + `hubTrack('<subject>', 1)` → действия уходят в общую систему достижений.
- В реестр `ACHIEVEMENTS` добавить коды `math_first`, `physics_first`, `informatics_first`,
  `russian_first` и пороги (10/25/50) — ачивки работают через существующий API.
- Карточки предметов в разделе «🎓 Школа» на хабе `/`.

#### 1.4. Порядок
1. Движок `/school/<subject>` + математика (полный паттерн, 60–80 задач).
2. Физика, информатика, русский — по тому же движку (наполнение данными).
3. Тесты: `tests/unit/test_school_module.py` (движок + каждый предмет), e2e-маркеры,
   ruff, `node --check`.

### Блок 2 — «Школьный хаб» (код)

- Раздел «🎓 Школа» на главной `/`: Математика, Физика, Информатика, Русский, История,
  Английский, Чтение.
- Существующие карточки/разделы не удаляются.

## Риски

- **Объём демо:** на защите рассказываем про 3–4 модуля, остальное — «также есть».
- **Честность про AI:** прямо указать, что при разработке помогали AI-инструменты
  (в школе это сейчас скорее плюс); архитектура, данные и тесты — «мои».
- **Секреты:** токены и `config/.env.local` не должны попасть в презентацию/доки.
- **Доказательство работы:** карта коммитов по датам + живые скриншоты с прода.
