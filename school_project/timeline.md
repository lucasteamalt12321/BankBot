## Как это доказать комиссии (если спросят)

Открыть на компьютере окно терминала в папке проекта и выполнить:

```bash
git log --reverse --date=short --format="%ad %h %s" | head -5     # первые изменения
git log -1 --date=short --format="%ad %h %s"                        # последнее изменение
git rev-list --count HEAD                                           # всего изменений (821)
git log --date=format:%Y-%m --format=%ad | sort | uniq -c           # изменения по месяцам
```

В GitHub то же самое видно без команд: вкладка **Commits** показывает историю
изменений по датам, а вкладка **Actions** — как автоматически запускаются тесты.

## Почему это можно назвать «своей» работой

- История изменений непрерывна и её нельзя «дорисовать» задним числом;
- изменения соответствуют этапам: сначала бот, потом портал, потом учёба;
- к каждому этапу есть код и автоматические тесты;
- проект действительно работает в интернете и им пользуется автор.

## Что честно сказать про AI

При разработке помогали AI-инструменты: они подсказывали по коду и помогали
писать тексты. Но:

- структура проекта (модули, слои) спроектирована автором;
- данные для предметов собирались и проверялись вручную;
- тесты запускаются и код проверяется автором;
- автор понимает каждую часть проекта и может объяснить её.

Это нормально для современной разработки — программисты сейчас работают вместе с
инструментами-помощниками.
