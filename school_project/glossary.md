# Глоссарий терминов (уровень 9 класса)

Короткие определения простыми словами. Их полезно знать, чтобы отвечать на
вопросы комиссии.

## Программирование и код

- **Python** — язык программирования. На нём написана основная («серверная») логика проекта.
- **Фреймворк** — «набор готовых деталей» для программы. Например, **Flask** — фреймворк для веб-сайтов на Python.
- **Библиотека** — набор готовых функций, который подключают к своей программе.
- **Модуль** — отдельная часть программы с одной зоной ответственности. У нас каждый предмет — отдельный модуль.
- **Архитектура** — то, как программа разделена на части и как эти части связаны.
- **Рефакторинг** — улучшение кода без изменения его поведения (чтобы было понятнее и проще).

## Интернет и сайты

- **Клиент** — то, что показывает результат пользователю (браузер).
- **Сервер** — программа, которая отвечает на запросы браузера.
- **Бэкенд** (backend) — серверная часть: логика, работа с базой данных.
- **Фронтенд** (frontend) — то, что видит пользователь на странице (HTML, CSS, JavaScript).
- **API** (Application Programming Interface) — «договорённость» о том, как программы общаются между собой. Например, страница спрашивает у сервера: «дай задачи по информатике», и сервер отвечает данными.
- **HTML** — язык разметки страницы (где заголовок, где кнопка).
- **CSS** — оформление (цвета, шрифты, размеры).
- **JavaScript** — язык, который «оживляет» страницу (реакция на клики, проверка ответов).
- **Хостинг** — место в интернете, где «живёт» сайт. Мы используем Vercel и Hugging Face Spaces.
- **Вебхук** (webhook) — способ, при котором внешний сервис сам отправляет сообщение нашему серверу. Так приходят сообщения от Telegram.
- **Домен** — имя сайта (адрес в интернете).

## Данные

- **База данных** (БД) — организованное хранилище данных (пользователи, прогресс, достижения).
- **SQL** — язык запросов к базе данных: «достать», «добавить», «обновить», «удалить».
- **CRUD** — четыре основные операции с данными: **C**reate (создать), **R**ead (прочитать), **U**pdate (обновить), **D**elete (удалить).
- **Таблица** — набор строк и столбцов в базе данных (как лист в таблице Excel).
- **ORM** (Object-Relational Mapping) — «переводчик» между программой на Python и базой данных. Вместо SQL пишут код на Python. У нас это **SQLAlchemy**.
- **СУБД PostgreSQL** — система управления базой данных; у проекта она в облаке (**Supabase**).
- **Миграция** — изменение структуры базы данных (например, добавить новый столбец).
- **Индекс** — ускоренная «закладка» в базе, чтобы поиск был быстрым.

## Качество и безопасность

- **Тест** — автоматическая проверка, что программа работает правильно.
- **Юнит-тест** — тест отдельной небольшой части программы.
- **Интеграционный тест** — тест, проверяющий взаимодействие нескольких частей.
- **Линтер** — программа, которая находит «грязный» код и ошибки стиля (у нас **ruff**).
- **CI/CD** — автоматическая проверка и публикация изменений. У нас при каждом изменении запускаются линтер и тесты (**GitHub Actions**).
- **Git** — система управления версиями: сохраняет историю изменений.
- **Коммит** — одна «сохранённая версия» изменений в Git.
- **Репозиторий** — хранилище проекта с историей изменений (у нас на GitHub).
- **Хостинг и домен** — место и адрес сайта в интернете.
- **Вебхук-секрет** — секретная строка, по которой сервер проверяет, что запрос
  пришёл действительно от Telegram, а не от злоумышленника.
- **Персональные данные** — сведения о человеке (имя, контакты). Их нельзя хранить
  в открытом доступе.

## Учебная часть

- **ОГЭ** — основной государственный экзамен за 9 класс.
- **ФИПИ** — организация, которая публикует материалы к экзаменам (кодификатор, задания).
- **Кодификатор** — список тем и требований, которые проверяются на экзамене.
- **Геймификация** — превращение учёбы в игру (достижения, «монеты», ежедневная активность).
- **Интервальные повторения** — приём запоминания: повторять материал через растущие
  промежутки времени (использован в тренажёре по истории).
