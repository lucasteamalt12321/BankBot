# Чек-лист подготовки к защите

Отмечайте пункты по мере готовности.

## Документы

- [ ] Заполнены личные данные в `passport.md`, `presentation.md`, `speech.md`
      ([ФИО], [класс], [школа, город], [ФИО руководителя], [дата защиты]).
- [ ] Паспорт проекта распечатан (если требуется).
- [ ] Презентация собрана (12 слайдов) и **проверена на компьютере класса/проекторе**.
- [ ] Речь отрепетирована вслух минимум 2 раза и укладывается в 5–7 минут.

## Скриншоты (сделать заранее!)

План проекта требует «живых» скриншотов с работающего сайта. Заготовьте:

- [ ] Главная страница с разделом «🎓 Школа».
- [ ] Информатика: список тем.
- [ ] Информатика: решённая задача с объяснением.
- [ ] Режим «Тест» (видно счёт и таймер).
- [ ] Математика: карточки формул.
- [ ] История: термины / повторение.
- [ ] Достижения (`/achievements`).
- [ ] Telegram-бот: 1–2 команды.
- [ ] Вкладка GitHub с историей изменений (доказательство работы).

## Проверка безопасности (обязательно!)

- [ ] В презентации и скриншотах **нет** токенов, паролей, ключей, адресов базы данных.
- [ ] Не открывать на защите вкладки с секретами (`.env`, панели администрирования).
- [ ] Не показывать персональные данные других людей.
- [ ] Проверить, что в проект не попали лишние файлы с приватными данными.

## Техническая подготовка

- [ ] Ссылки на сайт и репозиторий записаны в одном месте.
- [ ] Проверено, что сайт открывается (и есть резервное видео/скриншоты, если интернета нет).
- [ ] Ноутбук/телефон заряжены, есть переходник для проектора (если нужен).
- [ ] Закрыты лишние вкладки и уведомления, включён режим «не беспокоить».
