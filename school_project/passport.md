## 1. Актуальность

В 9 классе нужно готовиться к ОГЭ сразу по нескольким предметам. Обычно подготовка
распадается на десятки разрозненных источников: отдельные сайты, приложения,
тетради, случайные видео. Из-за этого:

- непонятно, что уже выучено, а что «провалено»;
- нет единого места, где виден прогресс по всем предметам;
- задания не всегда соответствуют формату ОГЭ;
- мотивация падает, потому что нет наглядного результата.

Проблема решается, если сделать **личную учебную платформу**, в которой собраны
задания по предметам и виден прогресс. Такую платформу можно сделать самому,
используя программирование, — что и является темой проекта.

## 2. Цель

Разработать личный учебный портал — веб-приложение (и связанный с ним
Telegram-бота) с модулями подготовки к ОГЭ по нескольким предметам, системой
прогресса и игровой мотивацией.

## 3. Задачи

1. Изучить, какие задания входят в ОГЭ по выбранным предметам, и собрать по ним базу.
2. Спроектировать архитектуру: отдельные модули для предметов, общий «движок» заданий.
3. Реализовать веб-портал с личным кабинетом, прогрессом и сохранением достижений.
4. Реализовать модули подготовки к ОГЭ: информатика, математика, русский язык, физика, история.
5. Добавить игровую мотивацию (достижения, «монеты», ежедневная активность).
6. Написать автоматические тесты и настроить автоматическую проверку кода при изменениях.
7. Опубликовать проект в интернете и проверить его работу на реальных пользователях (на себе).

## 4. Объект и предмет исследования

- **Объект:** процесс самостоятельной подготовки к ОГЭ.
- **Предмет:** программная платформа, которая организует эту подготовку
  (задания + прогресс + мотивация).

## 5. Гипотеза

Если собрать учебные задания по нескольким предметам в одну платформу с наглядным
прогрессом и игровыми достижениями, то готовиться к ОГЭ станет удобнее и
регулярнее, а результат будет виден в цифрах.

## 6. Методы работы

- анализ требований ОГЭ (что именно проверяется по предметам);
- проектирование архитектуры (разделение на модули);
- разработка (программирование на Python и JavaScript);
- тестирование (автотесты, ручная проверка);
- измерение результата (сколько заданий, какие модули, сколько тестов проходит).

## 7. Использованные технологии

| Технология | Для чего |
|------------|----------|
| **Python 3.12** | язык программирования и логика сервера |
| **Flask** | веб-сервер (страницы портала и внутренний API) |
| **python-telegram-bot** | Telegram-бот, который работает рядом с порталом |
| **PostgreSQL (Supabase)** | база данных: пользователи, прогресс, достижения |
| **SQLAlchemy** | работа с базой данных из Python (ORM) |
| **HTML, CSS, JavaScript** | внешний вид и интерактивность страниц |
| **Git и GitHub** | хранение истории версий, командная работа |
| **GitHub Actions** | автоматическая проверка кода (линтер и тесты) при каждом изменении |
| **pytest, ruff** | тесты и проверка качества кода |
| **Vercel, Hugging Face Spaces** | публикация (хостинг) проекта в интернете |

## 8. Этапы работы

Подробная карта с реальными датами — в файле [`timeline.md`](timeline.md). Коротко:

1. **Telegram-бот** (май 2026) — ядро, команды, «монеты», развлечения.
2. **Веб-портал** (лето 2026) — перенос функций бота в браузер, база данных PostgreSQL.
3. **Учебные модули** (август 2026) — подготовка к ОГЭ по 5 предметам, «Школа» на главной.
4. **Мотивация и качество** (сентябрь–октябрь 2026) — достижения, автоматические тесты,
   исправление ошибок и защита данных.

## 9. Результат

Создан действующий учебный портал, доступный в интернете, со следующими модулями
подготовки к ОГЭ:

| Предмет | Что реализовано (проверено по коду) | Объём |
|---------|--------------------------------------|-------|
| **Информатика** | Темы ОГЭ с теорией и задачами | **95 задач** |
| **Математика** | Формулы-карточки, задачи, генераторы вариантов | **50 задач + 130 формул + 8 генераторов** |
| **Русский язык** | Правила и задания | **45 заданий + 50 правил** |
| **Физика** | Формулы и задачи | **40 задач + 62 формулы** |
| **История** | Термины ОГЭ по периодам (тренажёр с интервальными повторениями) | **100 терминов** |

Дополнительно (существующие «школьные» модули):

- **Тренажёр чтения** (для младших классов) — с озвучиванием и печатью;
- **Практика английских глаголов** — генерация заданий;
- **Викторина** и **тренажёр по истории России**;
- **Достижения и ежедневная активность** — **325 достижений** в реестре.

Технические показатели:

- **821 коммит** в истории проекта (с 05.05.2026 по 18.10.2026);
- **более 1700 автоматических тестов** (юнит- и интеграционные);
- автоматическая проверка кода (линтер `ruff` + тесты) при каждом изменении через GitHub Actions;
- проект опубликован и работает в интернете.

## 10. Выводы

- Гипотеза подтвердилась: платформа действительно удобна в личном использовании
  и делает подготовку регулярной за счёт прогресса и мотивации.
- Удалось применить на практике разделение программы на **модули** (архитектура):
  новые предметы добавляются как отдельные модули на общем «движке».
- Получен опыт полного цикла разработки: от идеи и проектирования до публикации,
  тестирования и защиты персональных данных.

## 11. Практическая значимость

- Портал реально используется автором для подготовки к ОГЭ по 5 предметам.
- Материалы (задания, формулы, термины) собраны в одном месте и структурированы по темам.
- Проект можно развивать дальше: добавлять предметы, менять задания, расширять статистику.

## 12. Честность и ограничения

- При разработке использовались **AI-инструменты** как помощник (подсказки по коду и
  текстам). Архитектура, сбор данных, написание и проверка кода выполнены автором.
- Часть «взрослых» функций (магазин, экономика, игровые модули) — это дополнительный
  функционал портала, а не только школьная часть.
- Секреты (токены, пароли, база данных) **не** хранятся в открытом виде и не попадают
  в презентацию и документацию.
