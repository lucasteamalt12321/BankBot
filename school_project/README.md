# Школьный проект: материалы для защиты

Тема: **«Мой личный учебный портал: от Telegram-бота до платформы подготовки к ОГЭ»**
(9 класс, предмет «Информатика»).

Эта папка — «портфель» проекта: сам проект уже работает (сайт + бот), здесь лежат
документы, которые нужны для сдачи и защиты.

## Что лежит в папке

| Файл | Что это | Когда нужен |
|------|---------|-------------|
| [`passport.md`](passport.md) | Паспорт проекта: цель, задачи, методы, результат, выводы | Сдаётся в первую очередь, основа всего |
| [`presentation.md`](presentation.md) | Структура презентации по слайдам (12 слайдов) | Оформляется в PowerPoint / Google Slides |
| [`speech.md`](speech.md) | Текст речи на защиту (5–7 минут) | Учится наизусть/по опорным тезисам |
| [`demo_script.md`](demo_script.md) | Сценарий живого показа (версии на 5 и на 3 минуты) | На самой защите |
| [`timeline.md`](timeline.md) | Карта этапов разработки с реальными датами и числами | Ответ на вопрос «а ты сам это делал?» |
| [`glossary.md`](glossary.md) | Глоссарий терминов (ORM, БД, API, вебхук, CRUD и др.) | Ответы на вопросы комиссии |
| [`checklist.md`](checklist.md) | Чек-лист «что сделать перед защитой» | Финальная подготовка |

## Что нужно дописать руками (личные данные)

В файлах стоят заглушки в квадратных скобках — их нужно заменить на свои:

- `[ФИО]` — фамилия и имя;
- `[школа, город]`, `[класс]` — школа, город, класс;
- `[ФИО руководителя]` — учитель информатики;
- `[дата защиты]` — дата защиты проекта.

## Главная мысль защиты

Портал вырос из **личной необходимости**: сначала это был Telegram-бот для учёбы и
учёта «монет», потом к нему добавился веб-портал, а затем — **учебные модули
подготовки к ОГЭ**. Поэтому проект честный и живой: им реально пользуется автор.
